# AI Lead Generation Automation

An AI-powered lead generation and qualification workflow built with n8n.

## About the Project

This project automates the process of collecting and qualifying potential leads. A user submits their information through a form, the data is stored in Google Sheets, and an AI agent analyzes the lead based on the provided information.

## How It Works

1. A potential lead submits the form.
2. The submitted information is sent to the n8n workflow.
3. The AI agent analyzes the lead details.
4. The lead is assigned a qualification status, priority, score, and reason.
5. The results are stored in Google Sheets for easy review.

## Technologies Used

* n8n
* AI Agent
* Google Gemini
* Google Sheets
* Form Trigger
* AI Automation

## Key Features

* Automated lead collection
* AI-based lead qualification
* Lead priority classification
* Lead scoring
* Automatic results storage
* No-code workflow automation

## Project Purpose

The goal of this project is to demonstrate how AI and workflow automation can be used to simplify lead management and reduce repetitive manual work.
